# GTA VI Countdown

A fan-made countdown dashboard with a Vice City night scene.

**Open the site:** [https://jc-501-netizen.github.io/GTA-VI-Countdown-Timer/](https://jc-501-netizen.github.io/GTA-VI-Countdown-Timer/)

This is a fan project. It is not affiliated with, endorsed by, or associated with Rockstar Games.

## What it includes

- Live timers for the Extended Look, preload, and launch
- Achievement tracking and settings
- An animated background with independent airplane, helicopter, car, and boat traffic controls

## Open it locally

1. Download `index.html`
2. Open that file in a browser

No install is required. Everything is in one HTML file.

## Lights look too dark

Turn off page-darkening extensions such as Dark Reader for this site. The scene is already a night setting, and a second dark filter washes out headlights and building lights.
